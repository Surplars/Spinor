# Spinor 完整RVV目标与验收计划（M50）

目标仍为VLEN128、ELEN64配置下的完整V扩展实现。里程碑编号不是完成比例；本表按工作块跟踪，M50已统计314种算术编码的独立模型执行覆盖，尚未形成包含访存/系统异常的完整合规统计。RVA23另需核对其要求的Zvfhmin、Zvbb、Zvkt等扩展，不与基础V完成度混算。SEW64→128等超出本实现ELEN的保留形式不计为缺口；乱序/多发射也不是完整V的必要条件。

推进顺序：基础V编码审计、架构差分与编译器程序闭环，再补Zvfhmin等RVA23额外要求；在功能补齐过程中安排Orbital裸机程序闭环，最终完成架构/系统验证。每轮报告新增功能、剩余缺口、当前输入绑定验证范围、资源及固定300MHz条件预算，物理时序独立报告。

“已实现并通过现有回归”只证明相应范围，不等同于规范全部行为已验证。完整V声明需要所有目标指令/编码、架构状态、异常与内存模型达到目标规范，并有可复现架构测试证据；在此之前不得发布完整misa.V/RVA23支持声明。

M50对照采用未修改语义的Spike，TU/MU策略、合法frm、算术vstart=0；完整32行VRF和已实现CSR逐条比较。非零vstart、flush等由原Python/SoftFloat定向参考继续检查。下一轮优先扩展独立模型的向量访存及故障/重启测试，再补FP16转换和SoC系统边界。
