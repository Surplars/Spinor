# M42：估算指令与整数转换提速

本轮新增 `vfrec7.v`、`vfrsqrt7.v` 的 FP32/FP64 形式；整数→浮点转换减少串行归一化等待。仍为 VLEN128、ELEN64、单 lane、单指令在途的部分 RVV 实现。[完整性计划](rvv-completion-plan.md)、[验证报告](../reports/m42/evaluation.md)。

## 估算单元

标准编码为 funct6=0x13、OPFVV、vs1=5/4。使用已有 RAM 源读取和候选目的写回通路；独立 `FloatingPointEstimate` 分为按字节/位归一化、查表、指数、打包阶段，支持撤销、复位和结果反压，不增加 DSP。两张128×7位常量表由综合器映射为小型只读逻辑，没有为不足2 Kib的数据强制占用整块 BRAM；架构 VRF 继续使用 LUTRAM，没有增加整组寄存器快照。

这两条指令输出规范规定的七位估算，不等同于全精度除法/平方根。FP32/FP64达到完整精度通常还需要 Newton-Raphson 迭代。表和异常规则来自[RVV 1.0规范摘录](references/m42-estimates-v1.0.txt)。

处理正负零、无穷、qNaN/sNaN、负数平方根、非规格化输入、倒数溢出和非规格化输出；异常标志按规范为 NV/DZ/OF/NX，普通估算不额外设置 NX/UF。倒数溢出按五种 frm 选择无穷或最大有限数；`vfrsqrt7.v` 不读取舍入模式，frm=5/6/7也接受。M43规范审计确认：任何向量FP在无效frm下执行均为保留行为，接受或拒绝属于实现选择；可移植软件必须使用合法frm。

支持合法LMUL及分数LMUL、同宽源/目的别名、mask、vstart、VL0和空工作区。保留类型、组对齐、masked v0数据源/目的检查先于无工作判断。结果和私有fflags只在Completion接受时发布；撤销不会发布候选版本和异常标志。整数预设拒绝这两条FP指令。

## 转换提速

共享 `FloatingPointConvertResize` 在分段取绝对值后，将16/32位源直接放到64位归一化通路的高端；64位源原样保留。之后高字节为零时一次左移8位，否则移1位。数值、舍入、异常、接口和容量不变。

独立测试将冻结M41与当前转换器执行完全相同的11340组输入：16/32/64位、带/不带符号、五种舍入、所有二次幂附近边界和随机值。两边均通过固定SoftFloat数值参考，逐输入延迟减少量另用Python整数位长公式精确检查，禁止以“总周期更少”代替逐项验证。该测试集中最大等待由74周期降到25周期，单输入最多减少55周期；这些是转换单元周期，不是整条向量指令吞吐。

## 验证与限制

估算独立参考用精确整数分数和整数平方根计算区间中点舍入，不导入硬件表；另与全部256个规范表项交叉核对，并有8个字面量已知答案。RTL单元覆盖全部FP32/64指数、全部表项及区间边界、正负号、所有frm、随机数据和特殊值。整核模型直接检查32个架构寄存器、vstart/frm/fflags/版本、mask与别名。公开 `SpinorVpu` 增加规范FP32样例与FP64字面量测试。另用1、2、4、8循环的正有限数测量FP32/FP64、m1/m8的整条指令周期，配置与context访问不计入；异常输入矩阵的周期保留用于回归，不作为普通计算样例。

保留Mill、Chisel工具版本和M25固定条件时序模型，公共、计算/访存、四个预设均须在100 ps/段假设下≤3.333ns。该模型无布局布线，未按-2校准，排除DSP端点；不会将其结果当作ZU15EG实际300/500MHz签核。实际结果、资源和输入SHA见报告。

monitor ABI保留1.0，实现ID改为0x4201，能力位继续表示部分指令族。尚未真实接入Orbital、Linux作业驱动或完整RVV程序；下一步优先处理FP语义审计、跨步/索引访存和程序闭环。
