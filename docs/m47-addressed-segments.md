# M47：跨步与索引分段访存

新增56种`vlsseg2…8e8/16/32/64.v`、`vssseg2…8e8/16/32/64.v`，以及112种`vluxseg/vloxseg/vsuxseg/vsoxseg2…8ei8/16/32/64.v`，共168编码。加上M46的56种单位步长分段，当前ELEN64范围的普通分段形式已有实现；FOF仍未实现。保持VLEN128、单lane、单指令/单事务在途，仅物理普通RAM；仍不构成完整V/RVA23声明。见[完整性计划](rvv-completion-plan.md)。

## 地址和寄存器组

跨步地址是`base + element×stride + field×EEW/8`，支持正/负/零及小于字段总跨度的重叠步长。rs2=x0忽略scalar2；非x0寄存器值0也按零步长执行。两者目前均逐字段发出全部有效事务。索引地址是`base + zeroExtend(vs2[element]) + field×SEW/8`，索引是字节偏移，数据EEW=SEW/EMUL=LMUL，索引EMUL=LMUL×索引EEW/SEW。加法均模2^64；ordered按段序执行，unordered选择同样的合法顺序。字段内部选择按字段号递增。

数据EMUL×NFIELDS≤8、字段组对齐、寄存器尾端≤v31等规则仍成立。每个字段至少占一个物理向量寄存器；分数EMUL保留其余元素。索引组独立检查EEW/EMUL与对齐。**索引分段load的任何目标字段都不得与索引组重叠**，同宽也不例外；普通NF0索引load仍保留原来的合法重叠规则。store允许同EEW数据/索引源重叠，不同EEW保留。masked v0数据/索引源与EEW1掩码重叠继续拒绝。逐字段预检查在空VL、全mask关闭及vstart越界时也执行，非法形式不读取context或发总线请求。[规范摘录](references/m47-addressed-segments-v1.0.txt)。

VL、vstart和mask均以整段为单位；关闭段不访问字段。故障/停止允许当前段有已完成字段，vstart仍指向该段；宿主保留原基址和操作数，从该段字段0重新执行。已发布store不可撤销，停止需排空A/D，响应错误优先。普通RAM中的重复写回属于该重启策略，不能用于MMIO。

## RAM和时序改造

字段递进和跨步段首回退复用原来的四段16位加法器。跨步最后字段后先减去`(NFIELDS−1)×EEW/8`回到段首，再加原stride，包括零步长；索引每段只读一次对应索引。仅新增小模式与回退字节量，未增加64位地址银行、整组FF快照、RF端口、DSP或RAM。字段提交后复用空闲result寄存器保存地址增量，缩短加法器前选择链。rs2=x0的零操作数在命令接收时写入现有scalar2暂存，移除每次地址相加前的零选择器；不增加寄存器或周期。原非分段指令和M46单位步长分段的输入/周期继续核对。对现有8位进度暂存寄存器增加明确复位，保证冷启动首条指令直接发生访问错误时，映射仿真的进度输出也确定；没有新增数据银行。

EMUL的LMUL/EEW/SEW加减链改成七输入固定真值函数；对齐幂二组的尾端加法是冗余项，已去除。`prove_memory_geometry.py`以独立算术参考证明全部128个键、32个RF基址的组大小、范围、非负标志及边界检查等价，包括保留输入；它只证明组合译码，不证明整个LSU状态机。

## 验证范围

新增独立LSU模型覆盖168编码、合法数据/索引宽度和分数/整数LMUL、正负/零/重叠步长、mask空洞、vstart、v0/v31、高位索引零扩展、64位回绕、各字段别名、五类响应错误与停止竞争。完整和精简RTL/映射网表均逐命令核对全部64个RF块、完整64位总线地址及允许字段前缀；数据后端为8KiB循环空间，地址另行完整检查。

真实RAM/TileLink完整RTL核对全部32寄存器，精简两种ALU分段保留168编码、数据/索引组与保护寄存器、字段故障重试、mask空洞和部分字段停止。公共SpinorVpu用字面量验证负步长拆包、正步长打包、高位8位索引零扩展，以及VL0时最后字段别名拒绝；四个预设新增零步长重复与索引读写，实际16次新增事务。冷启动首错的真实LSU/宿主边界检查先于长矩阵执行。旧算术证据只有精确依赖/RTL/证据SHA均匹配才复用；访存与公共接口继续执行。

monitor实现ID为0x4701，ABI1.0和能力位不变。云端继续使用Yosys xcup、Icarus功能仿真及RapidWright家族表的固定M25条件预算，100ps/link、3.333ns门槛不变。未布局布线、未按ZU15EG-2校准，DSP端点排除；不等于器件300/500MHz签核。[评估结果](../reports/m47/evaluation.md)。
