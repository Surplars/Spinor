# M12 单块寄存器缓存

在 VectorMemoryEngine 内复用原有 64 位 original 寄存器作为单块缓存，仅新增有效位和 6 位寄存器块地址标签。此处缓存的是向量寄存器数据，不是内存 cache，不改变外部 TileLink 请求数量、地址或单事务约束。

每条指令接受时失效；首次或跨块时通过 context 读取。后续元素命中同一块可直接进入 sendMemory，跳过 context 请求及返回等待。store 源数据在整条访存期间由顶层独占，host context 和算术命令均被阻断，因此源缓存稳定。

load 用缓存中的完整块合并新元素，但仍按元素写回 committed 寄存器；只有 context 写回被接受时才把缓存更新为合并后的结果。后续元素因此保留此前加载的字节。没有延迟脏块写回，不改变故障可见前缀、未加载字节或尾部保持语义。

故障/停止后的新指令和重启一律重新取块，不能把上一条缓存带过去。已发布的请求仍排空，store 成功仍须提交 vstart，load 写回后仍须提交 vstart 才能停止。遵守 M10/M11 的不可撤销命令所有权合同，没有实际 CPU 异常接入。

验证保留全部访存数据、掩码、合法 EEW/EMUL、错误、停止和重启检查；新增 RTL 上下文读计数观测。24 组 128 字节基准应全部只读 16 个数据块加 2 次 mask 快照。映射后测试验证相同外部功能和周期，不依赖内部信号观测。make verify-m12 / make package-m12 可复现。

仍然只有单条访存指令、单个外部请求在途，没有新增 ISA 指令。下一步再评估多 source 请求和独立地址/数据调度。结构图跳数和周期模型均不等于器件 Fmax；没有新 Vivado 实现或 SDF 时序仿真。
