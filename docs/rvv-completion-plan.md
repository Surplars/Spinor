# Spinor 完整RVV目标与验收计划（M36）

目标仍为VLEN128、ELEN64配置下的完整V扩展实现。里程碑编号不是完成比例；本表按工作块跟踪，尚未形成逐编码完整合规统计。RVA23另需核对其要求的Zvfhmin、Zvbb、Zvkt等扩展，不与基础V完成度混算。SEW64→128等超出本实现ELEN的保留形式不计为缺口；乱序/多发射也不是完整V的必要条件。

| 工作块 | 当前状态 | 尚需实现/验证 |
|---|---|---|
| 基础整数 | 大部分计算、比较、归约、排列、mask已有实现；M36补vrsub及vmsgt[u] vx/vi | 进位/借位及全部编码审计 |
| 整数乘加 | M35单宽4类vv/vx；M36新增7种宽化乘加编码，含全部标准符号组合 | 完整架构差分与程序验证；乘加仍逐元素复用单元 |
| 定点 | 有宽窄移位和扩展 | 饱和加减、平均、饱和乘法、舍入移位、vnclip[u]与vxrm/vxsat完整语义 |
| 浮点 | FP32/64基本运算、FMA、同宽转换和归约 | 宽化算术/FMA、宽窄转换、估算倒数/倒平方根、标量搬运和vfslide1 |
| 整组搬运 | M36新增vmv1r/2r/4r/8r.v，版本化RAM复制，支持vstart、VL0和vill | 编译器寄存器搬运序列与完整架构差分 |
| 向量访存 | 单位步长、物理普通RAM、故障/停止前缀已有回归 | 跨步、索引、分段、FOF、整组与mask访存 |
| 架构验证 | 独立Python/SoftFloat参考、定向/随机回归和局部SAT | 完整规范逐项审计、独立ISA模型差分、编译器生成程序、异常/重启系统测试 |
| Orbital/SoC | 有宿主边界和物理TileLink接口，未真实集成 | VS/FS、精确异常、上下文、地址翻译/PMP、缓存一致性与内存模型 |
| ARM宿主 | monitor UIO用户态工具 | 计算任务提交代理/驱动，真实Linux/硬件测试 |

推进顺序：定点和进位/借位→剩余浮点→扩展LSU；在功能补齐过程中安排Orbital裸机程序闭环，最终完成架构/系统验证。每轮报告新增功能、剩余缺口、当前输入绑定验证范围、资源及固定300MHz条件预算，物理时序独立报告。

“已实现并通过现有回归”只证明相应范围，不等同于规范全部行为已验证。完整V声明需要所有目标指令/编码、架构状态、异常与内存模型达到目标规范，并有可复现架构测试证据；在此之前不得发布完整misa.V/RVA23支持声明。
